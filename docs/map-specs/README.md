# Rulebook map specs

How the Traders & Barbarians boards were translated from the 2025 rulebook
pictures into the engine's axial coordinates. Code comments refer to these by
name (TB-MAP-SPEC, TB56-MAP-SPEC, TBS-SPEC).

- `TB-MAP-SPEC.md` — the four original scenarios at 3–4 players, the T&B
  frame harbors, and the coordinate / edge / corner conventions.
- `TB56-MAP-SPEC.md` — the same four scenarios on the T&B 5–6 boards.
- `TBS-SPEC.md` — the Traders & Barbarians scenario (commodity hexes,
  interior paths, wagon board).

They were derived from high-DPI crops of `docs/catan traders and barbarians
rules.pdf` and `docs/catan traders and barbarians 5-6 rules.pdf`; image file
names and temp paths mentioned inside are scratch files from that session and
aren't kept. To re-check a map, render it with the preview tooling (CLAUDE.md,
"Checking a map against its rulebook picture") and compare it with the PDF
page.
